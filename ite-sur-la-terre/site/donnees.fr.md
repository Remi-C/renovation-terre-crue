Ce sujet est une synthèse : il ne publie pas de relevés propres. Il s'appuie sur les mesures des sujets [Vis dans la
bauge](../vis-dans-la-bauge/donnees.html) et [Humidité de la bauge](../humidite-de-la-bauge/donnees.html), et sur nos
calculs d'humidité, **non publiés à ce jour**. Le dossier [`ite-sur-la-terre/`]({{arbre_sujet}}) du dépôt GitHub contient
le code des figures. Texte et figures sous licence CC BY 4.0 ; code sous licence MIT.

## Le code

Python 3 avec matplotlib. Les figures sont des schémas de principe ; les seuls chiffres tracés (pesées publiées,
correspondances teneur en eau / humidité relative de nos calculs) sont écrits dans le script avec leur source. Depuis la
racine du dépôt :

```
python3 ite-sur-la-terre/code/figures_ite.py   # les trois figures (français et anglais)
make construire                                # tout, plus ce site
```
