This topic is a synthesis: it publishes no readings of its own. It relies on the measurements of the [Screws in
cob](../vis-dans-la-bauge/data.html) and [Moisture in cob](../humidite-de-la-bauge/data.html) topics, and on our moisture
calculations, **not published so far**. The [`ite-sur-la-terre/`]({{arbre_sujet}}) folder of the GitHub repository holds
the code of the figures. Text and figures under CC BY 4.0; code under the MIT licence.

## Code

Python 3 with matplotlib. The figures are schematic diagrams; the only numbers drawn (published weighings, water content
/ relative humidity correspondences from our calculations) are written in the script with their source. From the
repository root:

```
python3 ite-sur-la-terre/code/figures_ite.py   # the three figures (French and English)
make construire                                # everything, plus this website
```
