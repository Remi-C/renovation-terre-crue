# Code du sujet « ITE sur la terre » / Code

`figures_ite.py` trace les trois schémas du sujet, en français (`figures/<id>`) et en anglais (`figures/<id>_en`) ;
`--langue fr` ou `--langue en` n'en produit qu'une. Python 3 avec matplotlib. Schémas de principe ; les seuls chiffres
tracés (pesées publiées du sujet « Humidité de la bauge », correspondances teneur en eau / humidité relative des calculs
de l'auteur, non publiés) sont écrits dans le script avec leur source. *Draws the topic's three diagrams.*

```
python3 ite-sur-la-terre/code/figures_ite.py
```

- `figures_ite.py` — `fig_parements`, `fig_accroche`, `fig_regimes`.
